Файл правил

Кто здесь работает

Человек ставит цель и принимает результат.

Агент исполняет и оставляет след.

Правила агент молча не меняет.

02

В каком порядке читать

Сначала правила и границы.

Потом кто владелец папки.

Потом что делается сегодня.

03

Где живёт правда

Нужны задачи, идти сюда.

Нужен домен, идти в отдел.

Один факт живёт в одном месте.

Эти три ответа заменяют длинный промпт. Агент получает их из папки, а не из вашего сообщения.
