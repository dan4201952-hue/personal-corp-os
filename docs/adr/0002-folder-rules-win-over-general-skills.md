# 0002 · Правила папки сильнее общих скиллов

- Статус: принято
- Дата: 2026-08-06

## Контекст

Скилл живёт в папке, а не «глобально»: в рабочем штабе `weekly-retro` лежит внутри самой папки штаба, а у отдела есть собственный `retro`, который работает в границе одного домена и умеет переключаться между локальными файлами и трекером.

После установки плагина у человека одновременно доступны скиллы каталога и скиллы папки. Слово «ретро», сказанное в отделе, может означать две разные вещи.

## Решение

Побеждает папка. В `AGENTS.md` отдела прямо записано, что «ретро» здесь означает срез этого отдела и общий скилл не используется. Скиллы папки помечены `disable-model-invocation: true`, поэтому сами не всплывают: их поднимают правила.

Общий срез нескольких отделов запускается из штаба.

## Альтернативы

**Побеждает общий скилл, локальный вызывается явной формулировкой.** Отклонено: предсказуемо, но тогда папка ни на что не влияет, а именно композиция правил по папкам является главным свойством системы.

## Последствия

- Одно и то же слово даёт разный результат в штабе и в отделе. Это заявленное поведение, а не побочный эффект.
- Правила папки обязаны называть скиллы явной таблицей. Если правила не прочитаны, маршрутизация не работает.
- Скиллы папки лежат в видимой `skills/` без симлинков: симлинк молча ломается при скачивании на Windows без Developer Mode.
