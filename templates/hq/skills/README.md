# Скиллы штаба

> Слой правды. Скилл это записанный способ работы, который можно повторить. Он описывает, как получить результат, и сам результатов не хранит.

## Как скилл попадает в работу

Агент не угадывает, какой скилл взять. Его подключает таблица "Скиллы" в [`../AGENTS.md`](../AGENTS.md): запрос человека, путь к файлу скилла.

Поэтому папка видимая и обычная. Никаких симлинков: они молча ломаются при скачивании на Windows, и вы получаете нерабочую папку без сообщения об ошибке.

## Что кладут сюда

Скиллы **штаба** смотрят на систему целиком: срез недели по всем отделам, план недели, план дня, маршрутизация задачи в нужный отдел.

Скиллы **отдела** живут в самом отделе и работают только внутри своего домена. Смотрите `templates/department/skills/`.

Связка `retro → planning → daily` сохраняет недельный контекст. Retro фиксирует факт и цель Области, planning создаёт living plan на семь дней, daily мутирует актуальные маркеры плана без потери закрытых дней и локального состояния Wealth.

## Как добавить свой

1. Пройдите работу руками один раз.
2. Запишите последовательность шагов и условие остановки в `skills/<имя>/SKILL.md`.
3. Добавьте строку в таблицу "Скиллы" в `../AGENTS.md`.
4. Проверьте скилл на новом входе. Пришлось поправить, правьте сам скилл.

Скилл появляется из повторения. Не пишите скилл для работы, которую делали один раз.
