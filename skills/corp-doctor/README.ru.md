# Corp Doctor

Один вход во все операции над контуром Personal Corp: диагностика, ремонт, новый отдел, маршрутизация задачи.

Скилл начинается с меню и ждёт явного выбора, поэтому рабочий контур он не пересобирает вслепую.

| Пункт меню | Что происходит |
|---|---|
| Диагностика | Проход только на чтение по штабу, операционному слою и отделам; на выходе таблица расхождений |
| Починить | Закрывает найденные расхождения по одному согласованному изменению |
| Новый отдел | Preflight на чтение, сухой план, затем приватный corp-* репозиторий и одна строка в карте отделов |
| Маршрут задачи | Находит отдел по карте, проверяет дубли, создаёт задачу |
| Собрать с нуля | Штаб, правила агента, задачи первого уровня, первый отдел и договорённость про ритм |

Заменяет прежние скиллы `corp-init`, `corp-new` и `task-routing`.
