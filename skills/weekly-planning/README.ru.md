# Weekly Planning Skill

![Иллюстрация скилла](assets/illustration.png)

Скилл для Claude Code и Codex. Превращает результаты ретро и бэклог в приоритизированные outcomes, затем собирает живой вид полной недели, который обновляет локальный daily.

## Проблема

Планирование без структуры ведёт к реактивной работе, потерянным приоритетам и задачам не в тех репозиториях.

## Решение

8 шагов: собрать задачи → календарь → Области → Eisenhower → outcomes → issues → board → живой план недели.

- **Outcomes, не задачи** — формат "К пятнице X стало правдой"
- **Матрица делегирования** — решения фаундера vs исполнение агентом
- **Правильная маршрутизация** — issues в репо, где происходит работа
- **Конфиг из CLAUDE.md** — репо, роутинг, project ID
- **Полная ISO-неделя** — закрытые прошлые дни, выделенное сегодня и будущий план видны вместе
- **Area Explorer** — один источник карточек, фильтры, цели Областей и цвет по Области
- **Локальные привычки** — чекбоксы Wealth сохраняются в localStorage под ключом недели

## Установка

```bash
cp -r skills/weekly-planning ~/.claude/skills/
```

## Пререквизиты

Сначала запустите `corp-doctor` для генерации или ремонта конфига в AGENTS.md / CLAUDE.md, или добавьте вручную:

```markdown
## Agent Operations Config
repos:
  - owner/repo-1
  - owner/repo-2
project_id: N
owner: your-github-handle
routing:
  - pattern: "backend, bugs"
    repo: owner/backend-repo
```

## Процесс

| Шаг | Что происходит |
|-----|---------------|
| 1. Сбор | Бэклог ретро, открытые issues, календарь, ввод пользователя |
| 2. Календарь | Фиксированные события, дедлайны, обязательства |
| 3. Группировка | По поверхностям (продукт, продажи, контент и т.д.) |
| 4. Eisenhower | Срочность/важность + фаундер vs агент |
| 5. Outcomes | Измеримые результаты на неделю |
| 6. Issues | Создание в правильных репо с лейблом W{NN} |
| 7. Board | Всё на единый GitHub Project |
| 8. Живой план | Вычисление W{NN}, семь дней, Areas, часы и привычки Wealth |

## Часть фреймворка Personal Corp

```
corp-doctor → weekly-retro → weekly-planning → локальные daily-обновления → повтор
```
