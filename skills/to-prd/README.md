# To PRD

Turns what has already been discussed in the session (plus the codebase itself) into one PRD in the project folder — no new interview, synthesis only. The agent reads the repository, agrees testing seams with you, and writes `PRD.md` into the root of the feature or demo working folder.

**When to call it:** after [grill-me](../grill-me/) or any long conversation about a feature, when the decisions exist but there is no single document for the team and the next step.

**What you get:** `PRD.md` — problem/solution, a long list of user stories, implementation and testing decisions, out of scope.

**Next in the chain:** [to-issues](../to-issues/) cuts the PRD into vertical slices in `tasks/NN-slug.md`.
